# Три башни

Игра для Scratch: ставишь башни, покупаешь лучников и отбиваешься от волн орков.
Написана на [goboscript](https://aspiz.uk/goboscript/docs) — весь код лежит в текстовых файлах `.gs`.

## Как играть

- Три пустых места на траве — это места под башни.
- Щелчок по пустому месту строит башню — 5 монет.
- Щелчок по башне покупает лучника — 3 монеты, больше трёх на башню не влезает.
- Каждый лучник раз в секунду выпускает стрелу в того орка, который ушёл дальше всех.
- За убитого орка дают полмонетки. Орк, дошедший до края, отнимает жизнь, а жизней три.
- Победа — дойти до десятой волны.

## Сборка

> **Важно:** для сборки нужен goboscript **из PR [#406](https://github.com/aspizu/goboscript/pull/406)**.

Весь код проекта написан по-русски: имена переменных, процедур и спрайтов — кириллицей. Поддержку Unicode-идентификаторов добавляет именно PR #406, поэтому на обычном goboscript проект не соберётся.

Собрать goboscript из PR:

```sh
git clone https://github.com/aspizu/goboscript
cd goboscript
git fetch origin pull/406/head:pr406
git checkout pr406
cargo install --path .
```

Собрать сам проект — из папки, где лежит `goboscript.toml`:

```sh
goboscript build .
```

На выходе получится `tower.sb3` — его открывает Scratch.

Готовый `.sb3` в репозиторий не кладётся, он в `.gitignore`: собирать нужно самому.

## Что внутри

| файл | что это |
| --- | --- |
| `stage.gs` | сцена: поле, монеты, жизни, волна и общие списки |
| `башня.gs` | три места под башни, покупки и стрельба |
| `орк.gs` | выпуск волн и ходьба орков |
| `стрела.gs` | полёт стрел и попадания |
| `котик.gs` | правила и конец игры |
| `lib/константы.gs` | постоянные числа игры: цены, размер поля, скорость орка |
| `assets/` | картинки и звуки |

Все спрайты, переменные и процедуры названы по-русски — проект делался для ребёнка, который учит Scratch.

Числа, которые не меняются, вынесены в макросы `%define` в `lib/константы.gs`. Компилятор подставляет их прямо в блоки, поэтому в палитре переменных не появляется ничего лишнего, а в блоках стоят обычные числа. Заголовок подключается в каждый спрайт строкой `%include lib/константы`.
